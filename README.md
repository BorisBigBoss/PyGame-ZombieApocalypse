# PyGame-ZombieApocalypse

2D шутер с видом сверху, где вы сражаетесь против бесконечных волн зомби.

## Описание игры

В этой игре вам предстоит выживать в апокалипсисе, отстреливаясь от постоянно появляющихся зомби.

### Особенности:
- **Бесконечный спавн зомби**: Зомби появляются непрерывно, создавая нарастающую сложность.
- **Подвижный игрок**: Управляйте персонажем, перемещаясь по полю боя, чтобы уклоняться от атак.
- **Одно оружие**: В текущей версии доступно одно оружие для стрельбы по зомби.
- **Перспектива развития**: В будущих обновлениях все игровые сущности (игрок, зомби, пули) будут заменены на полноценные кадры анимации для улучшения визуального стиля.

## Требования

- Python 3.x
- PyGame

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd PyGame-ZombieApocalypse
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

Запустите игру командой:
```bash
python main.py
```

## Управление

- **WASD** или **Стрелки**: Перемещение игрока
- **Левая кнопка мыши**: Стрельба
